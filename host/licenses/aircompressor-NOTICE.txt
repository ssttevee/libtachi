PocketManga uses the pure Java io.airlift.compress.zstd.ZstdInputStream.
No Aircompressor native codec or zstd-kmp JNI implementation is included.

PocketManga modification: zstd package Unsafe get/putShort/Int/Long calls are
rewritten at build time to dev.tachi.host.AlignedUnsafe for ARM Zero alignment.
Other Aircompressor code and its public API are unchanged.
